# 🛠️ AltTools

### Платформа полезных онлайн-инструментов на Django

[![Django](https://img.shields.io/badge/Django-6.0-092E20?style=for-the-badge&logo=django&logoColor=white)](https://djangoproject.com)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=for-the-badge&logo=postgresql&logoColor=white)](https://postgresql.org)

**AltTools** — это веб-сервис, который собирает в одном месте десятки полезных инструментов: от финансовых калькуляторов до анализа текста и генераторов. Без регистрации, без навязчивой рекламы, без лишних кликов. Зашёл — посчитал — ушёл.

🌐 **Живой проект:** [alttools.ru](https://alttools.ru)

---

## 📖 О проекте

В интернете полно разрозненных калькуляторов: один сайт для ипотеки, другой для ИМТ, третий для конвертации величин. Все они перегружены рекламой, требуют регистрации или просто неудобны.

**AltTools решает эту проблему.** Это единая платформа, где собраны инструменты для разных сфер жизни:

- 💰 **Финансы** — кредиты, ипотека, вклады, сложный процент, доход на руки.
- 🏥 **Здоровье** — ИМТ, норма калорий.
- 🔢 **Математика** — проценты, медиана.
- 📏 **Конвертеры** — 10+ конвертеров величин.
- 📝 **Текст** — анализатор текста, форматтер.
- 🎲 **Генераторы** — случайные данные, QR-коды, пароли.

---

## ✨ Основные возможности

| Категория | Инструменты |
|-----------|-------------|
| **Финансы** | Кредитный калькулятор, ипотечный, вклады, сложный процент, калькулятор дохода на руки |
| **Здоровье** | Калькулятор ИМТ, суточной нормы калорий |
| **Математика** | Калькулятор процентов, медианы |
| **Конвертеры** | Конвертер величин (10+ типов) |
| **Текст** | Анализатор текста, форматтер |
| **Генераторы** | Генератор QR-кодов, паролей, случайных данных |
| **IT** | Форматтер JS,CSS-кода |

Каждый инструмент работает мгновенно — результат вычисляется прямо в браузере или на сервере, в зависимости от сложности.
