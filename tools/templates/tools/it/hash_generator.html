Что такое hash?

Hash — это результат работы хэш-функции. Она берёт входные данные любой длины и превращает их в строку фиксированной длины. Например, SHA-256 всегда выдаёт 256-битный результат, который обычно записывают как 64 hex-символа.

Хэши используют для проверки целостности файлов, сравнения данных, кэширования, цифровых подписей, хранения контрольных сумм и технических задач в разработке. Один и тот же текст всегда даёт один и тот же hash, но даже небольшое изменение входа создаёт совершенно другой результат.

Важно про безопасность

MD5 и SHA-1 считаются устаревшими для задач безопасности и не подходят для цифровых подписей, сертификатов, защиты паролей и проверки доверенных данных. Для обычных контрольных сумм они ещё встречаются, но для современных задач лучше использовать SHA-256 или более сильные алгоритмы.

Для хранения паролей нельзя использовать простой MD5 или SHA-256. Для этого нужны специальные алгоритмы вроде bcrypt, scrypt или Argon2 с солью и настройкой сложности.

FAQ

Частые вопросы о hash

Можно ли восстановить исходный текст из hash?

Обычно нет. Хэш-функции работают в одну сторону: из текста можно получить hash, но из hash нельзя надёжно восстановить исходный текст.

Почему у одинакового текста всегда одинаковый hash?

Хэш-функция детерминирована. Это значит, что один и тот же вход всегда даёт один и тот же результат. Именно поэтому hash удобно использовать для сравнения.

Чем SHA-256 лучше MD5?

SHA-256 выдаёт более длинный результат и считается намного надёжнее для современных задач. MD5 слишком слаб для безопасности и подходит только для простых технических проверок, где не важна защита от атак.

Можно ли использовать hash для проверки файла?

Да. Если у файла есть известная контрольная сумма, можно посчитать hash файла и сравнить значения. В этой первой версии инструмент считает hash текста. Хэширование файлов можно добавить отдельной функцией позже.

Безопасно ли вставлять сюда секретные данные?

Расчёт выполняется в браузере и не отправляет текст на сервер. Но всё равно лучше не вставлять реальные пароли, приватные ключи и production-токены в любые онлайн-инструменты.
