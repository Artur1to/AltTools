Как работает калькулятор УСН?

Калькулятор считает налог по упрощённой системе налогообложения. Для объекта «Доходы» налог считается с суммы доходов. Для объекта «Доходы минус расходы» налог считается с разницы между доходами и расходами.

В поле ставки можно указать стандартную ставку или свою региональную ставку, если для вашего региона и вида деятельности действует пониженный процент.

Формулы расчёта УСН

УСН «Доходы» Налог = доходы × ставка. Затем налог можно уменьшить на страховые взносы.
УСН «Доходы минус расходы» Налог = (доходы − расходы) × ставка. Если расчёт за год, дополнительно проверяется минимальный налог.
Минимальный налог Для объекта «Доходы минус расходы» по итогам года сравнивается обычный налог и 1% от доходов.
Уплаченные авансы Если авансы уже были уплачены, калькулятор вычитает их из итогового налога и показывает остаток к уплате.

Важное уточнение

Расчёт носит справочный характер. Он не заменяет бухгалтерский расчёт, декларацию и проверку региональных ставок. При УСН «Доходы минус расходы» учитывайте только те расходы, которые можно принимать для целей УСН.

Если вы применяете УСН и одновременно являетесь плательщиком НДС, НДС рассчитывается отдельно. Для этого на сайте можно использовать отдельный калькулятор НДС.
